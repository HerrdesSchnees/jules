# Agent Instructions for Jules

## Projekt-Kontext
Du bist der Hauptentwickler für dieses Projekt. Dein Ziel ist es, funktionalen, sauberen und gut dokumentierten Code zu schreiben.

## Codierungs-Richtlinien
- **Sprache:** Bitte schreibe Kommentare und Dokumentation auf [Deutsch/Englisch].
- **Stil:** Verwende modernes JavaScript (ES6+).
- **Struktur:** Trenne Logik (JS) strikt von Design (CSS).
- **Testing:** Wenn möglich, schreibe kleine Unit-Tests für neue Funktionen.

## Arbeitsweise
- Bevor du große Änderungen am UI vornimmst, erstelle einen detaillierten Plan.
- Fixe Bugs sofort, wenn du sie während der Entwicklung entdeckst.
- Wenn du Bibliotheken hinzufügen möchtest, frage mich vorher im Plan-Schritt.
